## 4. Existing Team Modules & Responsibilities

1. **`utils_io` (`src/utils/utils_io.py`):** Dynamic project path resolver (`resolve_project_paths`), robust TSV parser preserving string postal codes (`load_tsv_safe`), and atomic TSV writer (`save_tsv_safe`).
2. **`text_normalizer` (`src/normalization/text_normalizer.py`):** Unicode NFKD canonicalization, diacritics removal, French ligatures (`œ` -> `oe`), punctuation normalization, corporate legal suffix stripping (`inc`, `llc`, `corp`, `ltd`, `pvt`, `sarl`), and address abbreviation expansion.
3. **`structural_features` (`src/features/structural_features.py`):** Regex-based numeric token extraction ($\ge 3$ digits for PINs/ZIPs) and composite text representation (`clean_name + " " + clean_addr`).
4. **`audits` (`src/data/audits.py`):** Schema verification, null counting, whitespace checks, duplicate ID detection, and ID format regex validation (`^S[123]-\d+$`).
5. **`gt_profiler` (`src/evaluation/gt_profiler.py`):** Vectorized match cardinality, singleton rate evaluation, and source match attribution ($S_2$ vs $S_3$).
6. **`pipeline_clean` (`src/pipeline/pipeline_clean.py`):** End-to-end ingestion, normalization, and quality audit pipeline orchestrator.
7. **`blocking` (`src/blocking/blocking.py`):** Country-partitioned dual-channel TF-IDF character (3,4) n-gram candidate retriever.

## 9. Blocking Results & Bottleneck Analysis

### What Happened During Initial Run:
The original `blocking.py` script coupled two distinct operations into a single continuous script:
1. Validation benchmark on 20,000 $S_1$ records.
2. Full test candidate generation across all 1.73M test records against the 9.97M pool records.

### Root Cause Analysis of Local CPU Bottleneck:
- **Brute Force Matrix Dot Products:** Computing character (3,4) n-gram TF-IDF dot products for 1,732,544 queries against ~10,000,000 candidate records across 6,932 chunked matrix passes.
- **Row-by-Row Python Loop:** Sequential iteration calling `sims.getrow(i)` in Python on a single CPU core.
- **Local Compute Execution:** The process accumulated **71,445 active CPU seconds (~19.85 core-hours)** over ~22 hours without completing the final India candidate pass.
- **Decision:** Following explicit team agreement, the local brute-force process was cancelled at 16:38. Local execution for heavy computation is terminated; all heavy retrieval and model training will execute on cloud platforms (Kaggle / Colab / SageMaker).
