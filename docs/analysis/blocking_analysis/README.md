# Blocking & Candidate Generation Analysis

Evaluations of candidate generation filters, blocking strategies, and retrieval recall trade-offs.

## Key Metrics Evaluated:
- **Pair Completeness (Candidate Recall):** $\frac{|\text{True Matches in Candidates}|}{|\text{Total True Matches}|}$
- **Reduction Ratio (RR):** $1 - \frac{|\text{Candidates}|}{|S_1| \times (|S_2| + |S_3|)}$
- **Candidate Size:** Mean/median candidate pool size per $S_1$ entity.
