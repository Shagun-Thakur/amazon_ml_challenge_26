# Data Profiling Analysis

This directory collects exploratory data analysis (EDA) reports, distributions, and dataset statistics for Source 1, Source 2, Source 3, and ground truth tables.

## Focus Areas:
- Cardinality, record counts, and duplicate analysis per source.
- Length and token distributions of `business_name` and `business_address`.
- Country distribution (`US`, `India`) and missingness in train vs test.
- Distribution of ground truth match cardinality (proportions of 0-matches / singletons, 1-match, multi-matches).
